# Доверительная Бухгалтерия — статическая версия сайта (бенто)

Обычные HTML-страницы: ни сборки, ни DC-рантайма. Кладётся в корень репозитория
и работает на GitHub Pages как есть. Правится текстом в любом редакторе.

## Состав

```
index.html                  главная (13 блоков)
uslugi.html                 каталог услуг
usluga-<slug>.html          пять страниц услуг
usluga.html                 редирект со старых ссылок ?s=
calculator.html             калькулятор, 9 вопросов + результат
team.html                   команда
vacancy.html                работа у нас + анкета
blog.html                   статьи с фильтром по тегам
novosti.html                новости законодательства (список)
article-<slug>.html         57 страниц материалов
article.html                редирект со старых ссылок ?p=
contacts.html               контакты + карта + форма
privacy.html soglasie.html  политика и согласие
404.html                    страница не найдена
styles.css                  все стили сайта
site.js                     меню, аккордеоны, модалка, формы
articles.js                 материалы (собирается GitHub Action из _articles/)
uploads/                    шрифты Onest, логотипы, иконки, фото, SVG
robots.txt sitemap.xml
```

## Что нужно сделать перед публикацией

1. **Адрес приёма заявок.** В `site.js`, переменная `ENDPOINT` — подставить рабочий
   URL Google Apps Script (тот же, что был в старом `calculator.html`).
   Поле `type` уходит как `lead`, `calculator` или `vacancy` — как ждёт скрипт.
2. **Пересборка страниц материалов.** `article-<slug>.html` сгенерированы из
   `articles.js`. При добавлении материала в `_articles/` нужно перегенерировать
   страницу — либо сохранить прежнюю схему `article.html?p=slug` (редирект уже есть,
   но такая страница не индексируется поисковиками).
3. **Ссылка на МАХ** — сейчас заглушка `https://max.ru/` в подвале и на контактах.
4. **Часы работы** — стоит `Пн–Пт, 9:00–18:00` из текстов клиента, подтвердить.
5. **Резюме файлом** в анкете вакансии — ограничить типы и размер на стороне
   Apps Script (риск заражённого файла, п. 44 правок).
6. **Аналитика** — счётчики не подключены, вставить в `<head>` каждой страницы.

## Что не сделано и ждёт клиента

- «Ромашка» из фотографий сотрудников на первом экране — нужны фото всех.
- Раздел «Кейсы» отдельной лентой — нужны сами кейсы.
- Регалии и стаж по каждому сотруднику.
- Реальные цифры «20+ лет» и «100+ клиентов», формулировка «2 часа до ответа».
- Битрикс: заявки пока уходят только в Google-таблицу.

## Правки, внесённые по таблице Михаила

Пункт «Главная» в меню · одна кнопка на первом экране · плитка «20+» не чёрная ·
прямоугольная кнопка «Задать вопрос» · ссылки блоков перенесены вниз справа
одинаковыми кнопками · «Наша команда» вместо «Ваши бухгалтеры» · «Прошли проверку
ФНС после чужих ошибок» · «Автоматика справляется с простым учётом» ·
«Руководитель компании всегда на связи» · «Уточнить цену» ведёт в калькулятор ·
на контактах одна кнопка, телефоны с подписями · сводка по команде на странице
команды · SEO: title, description, canonical, og, sitemap, robots.

## Проверка

Локально: `python3 -m http.server 8899` из папки сайта.
Смотреть: нет битых картинок, отрисован подвал, нет горизонтальной прокрутки,
консоль чистая, формы не отправляются без галки согласия, на мобильной ширине
ничего не выходит за экран.
